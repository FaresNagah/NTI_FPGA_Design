# FPGA Packet Routing System

## Overview

A parameterized Verilog implementation of a small packet-routing network built around four FIFO input buffers, a round-robin arbiter, packet routing logic, and three memory-backed network nodes.

The project demonstrates how several RTL building blocks can be integrated into a complete synchronous communication system:

- Four input FIFOs buffer incoming packets.
- A round-robin arbiter selects which FIFO is allowed to transmit.
- The router decodes the packet destination and forwards the packet to the corresponding output port.
- Memory-backed nodes process read and write requests.
- Read responses are returned to the testbench through Port 3.
- The provided testbench exercises write and read transactions and verifies the returned address and data.

The project is organized into separate RTL modules so that the FIFO, arbitration, routing, memory-node, and top-level network functionality can be developed and verified independently.

## Packet Format

The implemented network uses a 24-bit packet format:

| Bits | Field | Description |
|---|---|---|
| [23:22] | Destination | Selects one of the four destination ports |
| [21] | R/W | 1 = write request, 0 = read request |
| [20:16] | Address | 5-bit memory address |
| [15:0] | Data | 16-bit payload/data field |

The destination field uses:

| Destination | Value | Port |
|---|---:|---|
| Port 0 | 2'b00 | Node 0 |
| Port 1 | 2'b01 | Node 1 |
| Port 2 | 2'b10 | Node 2 |
| Port 3 | 2'b11 | Testbench / response path |

For read responses generated by the memory nodes, the response destination is configured as Port 3.

## Main Modules

### FIFO Memory

<FIFO_Memory.v> implements a synchronous parameterized FIFO.

- Default data width: 8 bits.
- Default depth: 32 entries.
- Maintains separate read and write pointers.
- Maintains a count to generate empty and full.
- Supports synchronous write and read operations.
- Uses an active-low reset.

### Four FIFO Buffers

<Four_FIFO_Buffers.v> instantiates four identical FIFOs.

Each buffer has its own:

- Write enable.
- Read enable.
- Input data.
- Output data.
- Empty flag.
- Full flag.

For the router system, the buffers are instantiated with a data width of 24 bits and a depth of 16 entries.

### Round-Robin Arbiter

<RR_Arbiter.v> implements the arbitration logic.

The arbiter:

1. Tracks the FIFO that should receive priority.
2. Checks FIFO empty flags.
3. Grants one non-empty FIFO at a time.
4. Advances the priority after a successful selection.
5. Uses Router_Ready to control advancement.

The priority rotates through FIFO0 → FIFO1 → FIFO2 → FIFO3 and then returns to FIFO0, while skipping empty FIFOs.

### FIFO Arbiter System

<FIFO_Arbiter_System.v> integrates the four FIFO buffers with the round-robin arbiter.

It:

- Generates FIFO read enables from the arbiter grants and Router_Ready.
- Collects the four FIFO outputs.
- Selects the currently granted FIFO's packet.
- Generates packet_valid when a FIFO has been selected.
- Registers the selected FIFO information before presenting the packet data.

### Packet Routing

<Packet_Routing.v> receives a packet from the arbitration stage and routes it according to the two-bit destination field.

Only the selected output port is asserted as valid for an active packet.

A packet remains active until the selected destination port indicates that it is ready.

### Memory Network Node

<ram.v> implements a memory-backed network node.

Each node contains:

- 32 memory locations.
- 16-bit data per location.
- A request-processing FSM.
- Read/write request decoding.
- A response path for read operations.

For a write request, the node stores the 16-bit payload at the requested address.

For a read request, the node retrieves the stored data and generates a response packet addressed to Port 3.

### Network Top Level

<network.v> connects the router to three memory-backed nodes.

- Port 0 → memory node 0.
- Port 1 → memory node 1.
- Port 2 → memory node 2.
- Port 3 → testbench interface.

This wrapper provides the complete network used by the supplied system testbench.

### Router Top Module

<Router_TopModule.v> is the main router integration module.

It connects:

1. FIFO_Arbiter_System
2. Packet_Routing

and exposes the router's input FIFOs, output ports, valid signals, and FIFO status flags.

## Verification

The provided <n_tb.v> testbench performs an end-to-end verification of the network.

### Clock and Reset

The testbench generates a 100 MHz clock using:

~~~verilog
always #5 clk = ~clk;
~~~

The system is initially held in reset and then released before packet transactions begin.

### Write Transactions

The testbench writes three values to three different memory nodes:

| Destination | Address | Data |
|---|---:|---:|
| Node 0 | 4 | 16'hA1B2 |
| Node 1 | 10 | 16'hC3D4 |
| Node 2 | 31 | 16'hE5F6 |

### Read Transactions

The testbench then sends read requests for the same addresses and waits for the responses on Port 3.

Expected results:

| Address | Expected Data |
|---:|---:|
| 4 | 16'hA1B2 |
| 10 | 16'hC3D4 |
| 31 | 16'hE5F6 |

The testbench prints a [PASS] message when the returned address and data match the expected values and a [FAIL] message when they do not.

## Design Parameters

The main modules are parameterized to make the design reusable.

### Router Data Width

<Router_Top> and the surrounding routing system use:

- DATA_WIDTH = 24

### FIFO

The router's four FIFO instances use:

- WIDTH = 24
- DEPTH = 16

### Memory Nodes

Each memory node uses:

- DATA_WIDTH = 24
- ADDR_WIDTH = 5
- RAM_DEPTH = 32
- RESP_DEST = 2'b11

This gives each node 32 addressable 16-bit memory locations.
