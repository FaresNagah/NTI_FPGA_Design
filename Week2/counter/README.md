# Counter

## Overview

A Verilog counter module that increments its stored value on each active clock edge.

## Operation

The counter keeps a binary count and updates it synchronously with the clock. Depending on the implementation, reset can be used to return the count to its initial value.

## Verification

A testbench can be used to verify counting, reset behavior, and the counter output over multiple clock cycles.
