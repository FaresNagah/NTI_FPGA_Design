# Memory

## Overview

A Verilog memory module for storing and reading binary data using address-based access.

## Operation

The memory uses an address to select a storage location. Data can be written to the selected location and read back when required.

## Verification

A testbench can be used to verify writing data to different addresses and reading the stored values correctly.
