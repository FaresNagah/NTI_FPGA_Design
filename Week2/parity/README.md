# Parity

## Overview

A Verilog parity generator and checker used to generate or verify the parity of a binary data word.

## Operation

The parity logic determines the parity of the input data and produces the corresponding parity result. This can be used for simple error detection in digital communication and data transfer systems.

## Verification

The testbench verifies the parity logic using different input data patterns and checks the resulting parity output.
