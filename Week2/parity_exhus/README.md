# Parity Exhaustive

## Overview

An exhaustive verification of parity logic using a range of possible binary input combinations.

## Operation

The design is tested across the available input combinations to verify that the generated or checked parity result is correct for both even- and odd-parity cases.

## Verification

The testbench applies the input combinations and checks the parity result against the expected value. Exhaustive testing helps verify the parity implementation across all supported cases.
