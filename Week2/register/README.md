# Register

## Overview

A Verilog register module for storing and updating binary data on a clock edge.

## Operation

The register captures the input data when the clock edge occurs and holds the stored value until the next valid update.

## Verification

A testbench can be used to verify data loading, clocked updates, and data retention.
