# Sequence Detector

## Overview

A Verilog sequence detector that detects a predefined binary sequence in a serial input stream using sequential logic and a finite state machine (FSM).

## Operation

The detector processes the input sequence one bit at a time and changes its state according to the previously received bits. When the required sequence is detected, the output is asserted.

## Verification

The testbench verifies the detector by applying different input sequences and checking the detection output.
